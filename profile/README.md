<h2>◎ 組織概要</h2>
Lastelleoは、昨今のAIに依存していると言っても過言ではない風潮に対して疑問を呈す組織です。コードを生成AIに全て書かせる人は、おそらくこう言うでしょう。<br /><br />
<b>「ハーネスを適切に設計すれば、生成AIが作成したコードは間違っていない」と。</b><br /><br />
確かにそれは、間違っていないかもしれません。しかし、我々はコーディングが好きなのです。

我々は生成AIに依存する事で、我々の様々な能力が低下する事を懸念しています。<br /><br />

その為に、Laselleoは<b>最後までAIに依存しない伝承者</b>になるのです。
